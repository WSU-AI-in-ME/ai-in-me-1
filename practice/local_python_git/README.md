# Local Python Development and Git/GitHub

### ME 5995 — Fundamentals of Manufacturing Data Science
Wayne State University

Optional, ungraded self-study. Follow the supplied steps at your own pace;
there are no answers or files to submit. These guides use Windows PowerShell,
Python 3.13, Git, and VS Code. macOS/Linux setup is not covered.

## Choose your starting point

| Guide | What you will do |
|---|---|
| [Windows setup](windows_setup.md) | Install and check the tools on your own Windows laptop. |
| [Practice A](practice_a.md) | Create a project, run Python, add a graph to README, and save changes to your own GitHub repository. |
| [Practice B](practice_b.md) | Download the course example, install its requirements, run it, and open the saved graph. |
| [Command reference](quick_reference.md) | Look up commands used in the walkthroughs. |
| [Before leaving](before_leaving.md) | Save your results and sign out on a shared computer. |
| [Optional virtual environments](optional_venv.md) | Learn about separating project packages; not required for A or B. |

If the tools are already installed, you can start with either practice. The
main workflow uses user-level package installation with pip --user.

Screenshots show the instructor's examples. Use your own account and paths in
Practice A. The Windows setup checks and classroom A/B walkthroughs have been
reviewed; computer-specific installation permissions and paths may differ.
